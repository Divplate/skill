# Divplate skill

A skill that teaches a coding agent how to build a landing page or marketing site from [Divplate](https://divplate.com), a library of website sections for shadcn/ui and Tailwind v4.

```bash
npx skills add Divplate/skill
```

The skill holds no Divplate code and no key. It tells the agent how to choose blocks from the public catalogue and how to install them once the project is set up. Installing a block takes a Divplate license: see [pricing](https://divplate.com/pricing) and [getting started](https://divplate.com/docs/getting-started).
